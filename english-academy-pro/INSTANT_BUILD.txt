    🚀 ENGLISH ACADEMY PRO - INSTANT BUILD (30 MINUTES)
═══════════════════════════════════════════════════════════════════

QUICKEST METHOD: EAS Cloud Build (NO Computer Setup Needed!)

STEP 1: SIGN UP (2 minutes)
────────────────────────────────────────────────────────────────
1. Go to: https://expo.dev
2. Click "Sign Up"
3. Enter email & create password
4. Verify email

STEP 2: CREATE PROJECT (3 minutes)
────────────────────────────────────────────────────────────────
1. Login to Expo Dashboard
2. Click "Create App"
3. Select "React Native"
4. Name: english-academy-pro
5. Click Create

STEP 3: UPLOAD FILES (5 minutes)
────────────────────────────────────────────────────────────────
Create this folder structure in your project:

english-academy-pro/
├── App.tsx
├── app.json
├── eas.json
├── package.json
├── babel.config.js
├── tsconfig.json
├── ChatScreen.tsx
├── AnalyticsScreen.tsx
├── AdaptiveScreen.tsx
├── RewardsScreen.tsx
├── LeaderboardScreen.tsx
└── assets/
    ├── icon.png (512x512 - use any square image)
    ├── splash.png (1284x2556 - use any image)
    └── adaptive-icon.png

FILES TO COPY:
✓ App.tsx
✓ ChatScreen.tsx
✓ AnalyticsScreen.tsx
✓ AdaptiveScreen.tsx
✓ RewardsScreen.tsx
✓ LeaderboardScreen.tsx
✓ package.json
✓ app.json
✓ eas.json
✓ babel.config.js
✓ tsconfig.json

For assets, download from:
- icon.png: https://bit.ly/icon-512
- splash.png: https://bit.ly/splash-1284
- adaptive-icon.png: https://bit.ly/adaptive-icon

STEP 4: UPLOAD TO EXPO (5 minutes)
────────────────────────────────────────────────────────────────
1. In Expo Dashboard, click your project
2. Click "Files" or "Upload"
3. Drag & drop all files
4. Wait for upload to complete

STEP 5: BUILD APK (15 minutes - Automated)
────────────────────────────────────────────────────────────────
1. Click "Build" button
2. Select "Android"
3. Select "APK" (not AAB)
4. Click "Create Build"
5. Wait... (~15 minutes)
6. When done, click "Download"

STEP 6: INSTALL ON PHONE (2 minutes)
────────────────────────────────────────────────────────────────
1. Download APK to your Android phone
2. Open file manager
3. Find the APK file
4. Tap to install
5. Grant permissions
6. Open app

DONE! 🎉

ALTERNATIVE: If You Have A Computer
────────────────────────────────────────────────────────────────

Step 1: Install Node.js (nodejs.org)

Step 2: Run in terminal/command prompt:
  npm install -g expo-cli
  expo login
  
Step 3: Create project:
  npx create-expo-app english-academy-pro
  cd english-academy-pro

Step 4: Copy all TypeScript files into project

Step 5: Install dependencies:
  npm install

Step 6: Build:
  expo build:android

Step 7: Download & install APK

TIME: 45 minutes

🆘 PROBLEMS?

"Build failed"
→ Check internet connection
→ Try building again
→ Verify all files uploaded

"App won't install"
→ Android 8.0+? (Check Settings → About)
→ Have 100MB free? (Check storage)

"App crashes"
→ Uninstall & reinstall
→ Clear app cache
→ Restart phone
